Sunflower-friendly Events

PostgreSQL Europe is an official member of the Hidden Disabilities Sunflower, a globally recognised symbol that supports people living with non-visible disabilities. All PostgreSQL Europe events are invited and encouraged to become Sunflower-friendly. See the link above for more information, and contact the diversity committee to find out how help create events that are more understanding, more supportive, and more inclusive.
